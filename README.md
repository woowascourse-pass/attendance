# java-attendance-precourse

## 구현할 기능 목록

---

### 입력

- [ ] 기능 선택  
  ⇒ 1 : 출석 확인
  ⇒ 2 : 출석 수정    
  ⇒ 3 : 크루별 출석 기록 확인    
  ⇒ 4 : 제적 위험자 확인  
  ⇒ Q : 종료
- [ ] 닉네임 입력
  - 1, 2, 3번 기능
- [ ] 등교 시간 입력
  - 1번 기능
- [ ] 수정 날짜 및 시간 입력
  - 2번 기능
---
### 출력

- [ ] 날짜 및 요일 출력 + 기능 안내 
  ⇒ `오늘은 12월 13일 금요일입니다. 기능을 선택해 주세요.`  
  ⇒ `오늘은 12월 14일 토요일입니다. 기능을 선택해 주세요.`
- [ ] 기능에 따른 결과 안내
  1. 출석 확인
     - 출석한 날짜와 시간, 출석 상태 출력  
       ⇒ `12월 13일 금요일 09:59 (출석)`
  2. 출석 수정
     - 출석 변경 전 날짜와 시, 출석 상태 출력  
       ⇒ `12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!`  
  3. 크루별 출석 기록 확인
     - 출석 기록 및 출석, 지각, 결석 횟수 출력
       ```
       이번 달 빙티의 출석 기록입니다.
       
       12월 02일 월요일 13:00 (출석)
       12월 03일 화요일 09:58 (출석)
       12월 04일 수요일 10:02 (출석)
       12월 05일 목요일 10:06 (지각)
       12월 06일 금요일 10:01 (출석)
       12월 09일 월요일 --:-- (결석)
       12월 10일 화요일 10:08 (지각)
       12월 11일 수요일 --:-- (결석)
       12월 12일 목요일 --:-- (결석)
       
       출석: 4회
       지각: 2회
       결석: 3회
       
       면담 대상자입니다.
       ```
  4. 제적 위험자 확인
     - 제적 위험자 (면담, 경고, 제적 상태는 제외!!) 출력
       ```
       제적 위험자 조회 결과
       - 빙티: 결석 3회, 지각 2회 (면담)
       - 이든: 결석 2회, 지각 4회 (면담)
       - 쿠키: 결석 2회, 지각 2회 (경고)
       - 빙봉: 결석 1회, 지각 5회 (경고)
       ```

---
### 기능
1 : 출석 확인   
2 : 출석 수정    
3 : 크루별 출석 기록 확인  
4 : 제적 위험자 확인

- 시간은 24시간제

- 캠퍼스 운영 시간 : 매일 08:00 ~ 23:00
- 교육 시간은 
  - 월 : 13:00 ~ 18:00
  - 화~금 : 10:00 ~ 18:00
- 주말, 공휴일은 출석 X


- 5분 초과 ⇒ 지각
- 30분 초과 ⇒ 결석
- 등교 X or 출석 기록 X ⇒ 결석


- 경고 대상자: 결석 2회 이상
- 면담 대상자: 결석 3회 이상
- 제적 대상자: 결석 5회 초과

### 예외 처리

- [ ] 기능 선택 항목, 날짜 또는 시간을 잘못된 형식으로 입력한 경우   
  ⇒ "[ERROR] 잘못된 형식을 입력하였습니다."
- [ ] 등록되지 않은 닉네임을 입력한 경우  
  ⇒ "[ERROR] 등록되지 않은 닉네임입니다."
- [ ] 주말 또는 공휴일에 출석을 확인하거나 수정하는 경우  
  ⇒ "[ERROR] 12월 14일 토요일은 등교일이 아닙니다."
- [ ] 미래 날짜로 출석을 수정하는 경우  
  ⇒ "[ERROR] 아직 수정할 수 없습니다."  
- [ ] 등교 시간이 캠퍼스 운영 시간이 아닌 경우  
  ⇒ "[ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다."  
- [ ] 이미 출석을 하였는데 다시 출석 확인을 하는 경우  
  ⇒ "[ERROR] 이미 출석을 확인하였습니다. 필요한 경우 수정 기능을 이용해주세요."
